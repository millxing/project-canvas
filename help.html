A little room to think.

Project Canvas is a personal, local browser app. Open index.html to begin. The six starting projects are editable examples.

Your workspace

  • Each card is one project. Click its title or expand button to open the note editor.
  • Drag the top of a card to move it. Drag its bottom-right corner to resize it.
  • The minus button minimizes a card. Its expand button restores it.
  • Use the card’s menu to duplicate, change layers, archive, or remove it from the canvas.
  • Removing from canvas keeps the note in All projects. Archive puts it in Archive. Delete moves a project to Trash, where you can restore it even after closing the app. The immediate Undo action and Ctrl/Cmd Z outside the editor also restore the last deleted project during this session.
  • New project adds a card and opens its editor. Everything is editable, including titles and descriptions.

Notes and images

Open a card to expand it into an editing window. Press Escape, click outside the window, or use the close button to return to the canvas.

Use the editor toolbar for headings, paragraphs, bold, italic, bullet lists, and images. You can also paste images or drop image files into the note. Images are resized to a maximum of 1400 pixels and GIFs become still images. Select a folder and card color below the title.

Drag an image already in a note to move it; a purple insertion marker shows its destination. Click or right-click an image for Copy image, Save image as…, Open image, Move image up/down, and Delete image. Deletion offers an Undo button. You can also focus an image and press Delete or Backspace to remove it. Hold Shift while right-clicking to request the browser’s native menu.

Import a Bear note by dragging

Open index.html directly and click Import Bear note. Drag a whole note from Bear’s middle note list into the target. Bear supplies a .bear package; this app unpacks its Markdown and images entirely in your browser. No export step, server, or Bear database connection is needed. You can also drop a .bear package directly onto the canvas or a project note, or choose a .bear file.

The title, headings, bold, italic, underline, highlighting, lists, checklists, links, tables, and code formatting carry over. PNG, JPEG, GIF, and WebP images are embedded and save with the project and backups. Missing or unsupported images appear as placeholders with an import warning. Other attachments and Bear internal links are preserved as text with a warning. Fonts follow this app’s Verdana styling, and code does not receive syntax coloring.

An empty untitled project is filled; otherwise a new project is created. Bear originals remain untouched. Imports are independent copies, not ongoing sync. Packages are limited to 100 MB compressed and expanded, 2,000 entries, 10 MB note text, and 30 MB per attachment.

Links and YouTube videos

Select note text and click Insert or edit link to make a hyperlink, or enter both an address and a label in the dialog. Select an existing link and use the same button to edit it. Remove link keeps the text and removes its destination. Links open in a new tab when clicked.

Use Embed YouTube video to insert a YouTube watch, share, Shorts, or live URL. Videos play inside the note and have Open on YouTube and Remove video controls. Embedding depends on an internet connection and the video owner allowing playback on other websites. Links and video references save with notes and are included in backups.

For embedded playback, double-click Start Project Canvas.command. It runs the app at http://127.0.0.1:4173 and opens your default browser. Keep its Terminal window open while using the app. YouTube requires a web origin; opening index.html directly shows a watch-on-YouTube fallback instead. The launcher needs Python 3, which is installed on this machine.

Move existing notes once: In your current file-based app, use Backups & help → Export backup. Launch Start Project Canvas.command in the same browser, then use Import backup. The file address and local web address have separate browser storage. Keep the exported backup until you have checked your imported notes.

Checklists

Click the Checklist button in the note toolbar to turn the current paragraph or bullet list into tasks. Click a checkbox to complete a task; completed text is crossed out. Press Enter to add another unchecked item. Press Enter on an empty item to return to normal text. Backspace at the start of a task converts that item back to a paragraph. Click Checklist again, or Bullet list, to turn a checklist into ordinary bullets. Checked states save automatically and are included in backups. Checkboxes are read-only while a project is in Trash.

Finding and arranging things

Use the menu beside a folder to rename it, move it up or down, or delete it. You can also drag folder names to change their order. Renaming keeps every project assigned to that folder. Its projects move to Unfiled and remain in All projects, including archived projects in Archive. The toast offers Undo to restore the folder and its project assignments.

Search titles, subheadings, folder names, and note contents using the search field or Ctrl/Cmd K. Search covers active projects; choose Archive first to search archived projects. All projects and folders are sorted by last edited. The canvas remains in the arrangement you chose.

The amber box at the top of the canvas is the hot zone, for projects you are working on now. Drag a card into it. The box grows and shrinks to fit its cards. Drag the tab on its top edge to move it, or the thin handles on its bottom and right edges to resize it. Double-click a handle to fit the box to its cards. In grid layout, use a card’s menu: Add to hot zone. Cards and the zone snap to a 20-pixel grid, shown as faint dots. Tidy canvas arranges visible cards into rows. The grid button switches between a free canvas and a tidy reading grid; use Move earlier / Move later in a card’s menu to reorder the grid. On a free canvas, use Bring to front / Send to back. Use zoom and Fit all to get your bearings. The palette button changes the solid canvas background.

Trash and restoration

Deleted projects stay in Trash with their notes, images, folder, size, and canvas position intact. Trash is separate from All projects, Archive, and active search. Use Restore in Trash to bring a project back to its previous state. Archived projects return to Archive. Trashed notes can be read but must be restored before editing. Open a trashed note’s menu to delete it permanently, or use Empty trash to remove all trashed projects. Both require confirmation and cannot be undone. Backups include Trash.

Saving and backups

Changes, card positions, folders, images, and colors save automatically in this browser using IndexedDB. They are specific to this browser profile and app location. Clearing browser site data removes them. There is no cloud sync.

Use Backups & help → Export backup regularly. A backup includes every project and embedded image. Import replaces everything on your canvas, including folders and Trash, with the contents of the backup. A confirmation appears first. Export a backup before importing if you want to keep your current projects. Browser storage problems appear in the sidebar; export a backup if you see an error.

You can open the app directly as a file. For a stable local address, run python3 -m http.server 4173 --bind 127.0.0.1 in the app folder and visit http://127.0.0.1:4173. File and server addresses have separate browser storage, so use export/import when moving between them.

Keyboard access

Tab to a card and press Enter to open it. On a free canvas, arrow keys move a focused card by one grid step (20 pixels); Shift + arrow keys resize it. Escape closes the editor or menu. Standard text editing shortcuts work inside the note.
